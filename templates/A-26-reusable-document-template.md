# A-26: Reusable document template

Use when you produce the same kind of document repeatedly.

```text
Create a template for {DOCUMENT TYPE}.
Company: {NAME}, {BUSINESS}. Style: {formal / neutral}.
Sections: {1}, {2}, {3}.
Use {VARIABLE} placeholders such as {CLIENT_NAME}, {DATE}, and
{AMOUNT} for everything that changes.

Give the template, a list of all variables with descriptions,
and one completed example.
```

Source: *Claude Cowork: Build Your Own AI Team*, Appendix A, Organizational documents.
