# A-49: Project instructions

Use when setting up a new Project.

```text
Write instructions for a new Claude Project.
Purpose: {WHAT THE PROJECT IS FOR}
User: {NAME, ROLE, ORGANIZATION}
Main jobs: {THREE TO FIVE}
Style: language {LANGUAGE}; tone {TONE}; answer length {LENGTH}
Facts Claude must know: {1}, {2}
Always: {RULES}
Never: {PROHIBITIONS}

Write complete instructions I can paste in and use immediately.
```

Source: *Claude Cowork: Build Your Own AI Team*, Appendix A, Thinking tools and routines.
