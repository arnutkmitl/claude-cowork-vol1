# A-45: Data storytelling

Use when numbers must persuade.

```text
Based on the data and analysis so far, write a three-paragraph
data story: the situation (where we are, key figures); the
challenge (the main problem and why); the opportunity (the way
forward and what happens if we act). Cite at least three key
figures. Make it engaging and make readers want to act.
```

Source: *Claude Cowork: Build Your Own AI Team*, Appendix A, Thinking tools and routines.
