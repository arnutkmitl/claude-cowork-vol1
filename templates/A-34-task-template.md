# A-34: Task template

Use to turn a recurring job into a reusable task.

```text
Write a task template for: {TASK}
Details: {WHAT IT INVOLVES}. Frequency: {HOW OFTEN}.

Use this structure:
TASK: {NAME}
INPUT: {VARIABLES WITH DEFAULTS}
STEPS: {NUMBERED STEPS}
OUTPUT: {RESULTS}
CHECK: {HOW TO CONFIRM SUCCESS}
Include a preview-and-approve step before any file changes, and
an undo log.
```

Source: *Claude Cowork: Build Your Own AI Team*, Appendix A, Automation.
