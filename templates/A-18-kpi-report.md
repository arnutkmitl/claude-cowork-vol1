# A-18: KPI report

Use when you report KPIs against targets with traffic-light status.

```text
Build a KPI report from this data.
{DATA: KPI, target, actual, last month}

1. Status: Green (100% of target or more), Amber (80 to 99%),
   Red (below 80%). Note any KPI where lower is better.
2. Likely causes for every Amber and Red KPI
3. Two actions with dates for every Red KPI
4. A forecast for next month if trends continue
```

Source: *Claude Cowork: Build Your Own AI Team*, Appendix A, Data analysis.
