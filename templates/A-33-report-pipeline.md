# A-33: Report pipeline

Use to turn spreadsheet data into a report and an email draft.

```text
Run the report pipeline.
Data: spreadsheet {NAME OR URL}, sheet {NAME}, period {PERIOD}.
Analysis: KPIs {FIVE KPIS}; compare with {target / last
month / last year}; three highlights and two areas to improve.
Output: a document "{NAME}, {MONTH YEAR}" with executive
summary, KPI table, highlights, and recommendations; a Gmail
draft to {RECIPIENTS}, subject "{NAME} is ready", with five key
points and the report. Report after each step. Create a draft
only; do not send anything.
```

Source: *Claude Cowork: Build Your Own AI Team*, Appendix A, Google Workspace.
