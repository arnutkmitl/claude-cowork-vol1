# Appendix A: 50 prompt templates

One file per template from Appendix A of *Claude Cowork: Build Your Own AI Team*, text exactly as in the book. Open a file, copy the prompt, and replace the placeholders.

## How to use the templates

1. Find the template for your task in the index below (the book prints it as "Find a template by task"), or browse the files by group.
2. Copy the whole template into Claude, ideally inside the Project that fits the work.
3. Replace every `{PLACEHOLDER}` with your own details. Delete optional lines you do not need.
4. Send it, check the result, and refine with feedback (Chapter 3).
5. Templates that say *my inbox*, *my calendar*, or *open it from my Drive* (A-28, A-30, A-31, A-33, A-47) need the Gmail, Google Calendar, or Google Drive connector (Chapter 2). A-33 also needs **Create and edit files** turned on in **Settings** > **Capabilities**.

## Conventions

| Convention | Meaning |
|---|---|
| `{PLACEHOLDER}` | Replace with your own information |
| `{option A / option B}` | Choose one |
| `{e.g., example}` | A hint; replace it with your own value |
| `{ATTACH THE FILE}` | Upload or attach a file at this point |
| "if any" | Include only when you have the information |
